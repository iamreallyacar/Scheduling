# CLAUDE

## GUIDELINES

- When a request leaves the end goal open, state the goal you are working to before starting.
- Read relevant documents before responding to ensure that your response aligns with existing information.
- Honesty and clean solutions are valued more than request completion.
- If a request is large and risky to undertake in one go, perform task decomposition, update the task list with the decomposed task, and inform the user before starting.
- If during the completion of a request, you ran into more problems than expected, inform the user at the end of the request, and recommend improvements to the instruction set, documentation, existing code structure, or any other aspect that can allow future work to run more smoothly.
